# 软件杯项目 - 一键启动

## 前置要求
- 安装:可以到应用商店下载 Docker Desktop
- 配置好docker,这样就不用配环境了
## 启动步骤
1.按win+x点打开终端
#
2.cd C:\Users\84293\Desktop
#
3.git clone https://github.com/IWantBeABoss/ruanjianbei.git ruanjianbei-test
#
4.cd ruanjianbei-test
#
5.把你本地的backend/.env.example该名成.env，并把.env中我标记了的地方改为我群里发的apikey(注意把对应的#给删掉)。
#
6.docker-compose up -d
#
7.访问:http://localhost:8080
