# 软件杯项目 - 一键启动

## 前置要求
- 安装:可以到应用商店下载 Docker Desktop
- 配置好docker,这样就不用配环境了
## 启动步骤

1.cd C:\Users\84293\Desktop
2.git clone https://github.com/IWantBeABoss/ruanjianbei.git ruanjianbei-test
3.cd ruanjianbei-test
4.把你本地的backend/.env.example该名成.env，并把.env中我标记了的地方改为我群里发的apikey(注意把对应的#给删掉)。
5.docker-compose up -d
6.访问:http://localhost:8080
